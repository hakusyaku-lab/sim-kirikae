# SIM切替（SimKirikae）

デュアルSIMの Android スマホ／タブレットで、**データ通信に使うSIMを①⇔②に1タップで切り替える**アプリです。
設定アプリを何画面も開かずに、ホーム画面のアイコンやクイック設定のタイルから切り替えられます。

- アプリ画面：大きな「SIM①」「SIM②」ボタン（使用中のSIMが青）
- ホーム画面のショートカット：アイコン長押し →「SIM①」「SIM②」「SIM切替」（ホームに置けます）
- クイック設定のタイル：「データ SIM①」「データ SIM②」

> Android ではふつうのアプリがデータSIMを切り替えることは許されていないため、**[Shizuku](https://shizuku.rikka.app/)（無料）が必要**です。root化は不要です。

## 使える端末

| | Android | iPhone | Windows | Mac |
|---|---|---|---|---|
| アプリ本体 | ○（Android 8 以上・デュアルSIM機） | ✕（下の「iPhoneの場合」） | － | － |
| 導入の手伝い（PCから入れる） | － | － | ○ `pc/windows` | ○ `pc/mac`（Linuxも可） |

動作確認済み：ALLDOCUBE iPlay 80 mini Ultra。メーカー独自の改造が大きい機種では動かないことがあります。

## 入れ方

### かんたん：PCから自動で入れる
1. スマホ／タブレットで「USBデバッグ」をONにする
   設定 → 端末情報 →「ビルド番号」を7回タップ → 設定 → システム → 開発者向けオプション →「USBデバッグ」
2. USBでPCにつなぐ
3. このリポジトリの `pc` フォルダをダウンロードして実行
   - **Windows**：`pc/windows/1_導入する.bat` をダブルクリック
   - **Mac**：`pc/mac/setup.command` をダブルクリック（初回は右クリック →「開く」）
4. 端末に「USBデバッグを許可しますか？」が出たら「常に許可」→「許可」

ADB（Google公式）・Shizuku・SIM切替の最新版を自動でダウンロードして入れ、Shizuku を起動します。

### 手動で入れる
1. [Shizuku](https://shizuku.rikka.app/) を入れて起動（PCの `adb` から、または Android 11 以上なら端末だけで「ワイヤレスデバッグ」から）
2. [Releases](../../releases/latest) から `SimKirikae.apk` をダウンロードして入れる
3. 「SIM切替」を開き、Shizuku の許可で「常に許可」

## 再起動したとき
Shizuku は端末を再起動すると止まります。PCにつないで `2_Shizukuを起動する.bat`（Macは `setup.command start`）を実行するか、Shizuku アプリの「ワイヤレスデバッグで起動」でもう一度動かしてください。
止まっているときは、アプリやタイルに「Shizukuが動いていません」と出ます。

## 切り替えにかかる時間
ボタンを押すとすぐに切り替えの指示を出します。そのあとネットにつながる（4G/LTE が表示される）までの数秒〜十数秒は、端末の通信部品とキャリア側の処理なので、どのアプリでも変わりません。

## iPhoneの場合
iPhone ではアプリからデータSIMを切り替える方法が Apple から用意されていないため、このアプリの iPhone 版は作れません。代わりに次の方法が近道です。

- **iOS 18 以降：コントロールセンター**（2タップ）
  コントロールセンターを開く → 左上の通信ボタンのかたまりをタップ →「モバイル通信」→ 使いたい回線を選ぶ（チェックが付いているのが使用中）
- **ショートカット App で設定画面を1タップで開く**（未確認：iOS の版によっては開けないことがあります）
  1. ショートカット App →「＋」→「アクションを追加」→「URL」を選び、
     `prefs:root=MOBILE_DATA_SETTINGS_ID&path=MOBILE_DATA_SETTINGS` と入力
  2. 続けて「URLを開く」を追加
  3. 右上の共有ボタン →「ホーム画面に追加」
  開いた画面で「モバイルデータ通信」の回線を選びます。

## しくみ・安全性
- 切り替えは、設定アプリの「データ通信のSIM」を選んだときと同じ処理（既定のデータSIMを変更 → そのSIMのモバイルデータをON）を Shizuku 経由で呼び出しています。
- 通信・広告・データ収集はありません。インターネットの権限も持っていません。
- 他のアプリからこのアプリに切り替えを頼むことはできません（切り替え用の画面は外部に公開していません）。
- 切り替え処理は [DataSimTile](https://github.com/Mygod/DataSimTile)（Apache-2.0）を参考にしています。

## 自分でビルドする
GitHub Actions が push のたびに APK を作ります。main への push で Releases の `latest` が更新されます。
本番の署名鍵はリポジトリに入れず、Secrets（`SIGNING_KEYSTORE_B64`・`SIGNING_PASSWORD`）から渡します。鍵が無いフォークでは開発用の鍵で署名されます。
